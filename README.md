# Flok

**Flok** — уютный мессенджер с подарками, маркетом, каналами и собственной валютой.
Сделан в эстетике **Glassmorphism 2.0 / Organic Minimalism**: мягкое стекло, живые
градиенты, округлые формы и спокойные анимации.

> Flok 1.0 · офлайн-версия. Аккаунт, чаты, подарки и маркет сохраняются на устройстве.
> Для общения с реальными людьми на разных устройствах нужен Flok-сервер (см. ниже).

## Что внутри

- Вход и регистрация по `@нику` и паролю; e-mail и телефон — по желанию.
- Чаты с людьми и персонажами Flok, поиск по нику, e-mail и телефону.
- Каналы с постами; можно создать собственный канал.
- **33 подарка**: 30 обычных редкостей и 3 хэллоуинских лимитки. У каждого подарка
  есть редкость, тираж и серийный номер.
- **Маркет**: покупка, продажа, быстрая продажа, подарок другому человеку.
  Магазин берёт 5% с продажи.
- **Flok** — внутренняя валюта. Кликер, ежедневный бонус, авто-дроны и продажи.
- **Профиль**: витрина подарков и фоны, включая три космических. Фон и витрину
  видят другие пользователи.
- Тёмный стеклянный интерфейс, нижняя навигация, адаптация под телефон и десктоп.

## Локальный запуск

```bash
# просто открыть web/index.html в браузере
# или поднять статический сервер:
python3 -m http.server 8080 --directory web
```

Для сборки Android нужны Node.js 22, JDK 21 и Android SDK; для Windows —
Node.js 22. Всё это уже настроено в GitHub Actions.

```bash
npm install
npm run test:web        # jsdom smoke-тест
npx cap add android
npx cap sync android
```

```

desktop/      Electron-обёртка для Windows
```

## Данные и приватность

В офлайн-режиме всё лежит в `localStorage` браузера/WebView. Очистка данных
приложения удалит аккаунт и подарки. Пароль хранится как SHA-256-хеш с солью.
Flok — не деньги и не криптовалюта; внутренняя валюта не имеет денежной стоимости.
